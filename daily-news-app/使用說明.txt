聲讀 DAILY｜每日全球政經新聞朗讀播放器
網址：https://ada868.netlify.app

【一、上傳到 Netlify】
1. 登入 Netlify → 進入 ada868 這個網站 → 上方「Deploys」。
2. 把解壓縮後的整個資料夾（裡面直接看到 index.html 的那一層）拖進頁面下方的上傳區。
   注意：index.html 必須在最外層，不能多包一層資料夾。
3. 部署完成後，用手機開 https://ada868.netlify.app 確認。

【一之二、建議：連結 GitHub，啟用「伺服器版」（新聞更快、更穩定）】
手動拖拉上傳的網站只能由手機瀏覽器經免費轉接服務抓新聞，速度慢、常失敗。
網站連結 GitHub 後，Netlify 伺服器每 10 分鐘整理一次新聞（抓取、翻譯、套用編輯原則），
手機只要讀一份整理好的結果，通常 1 秒內就出現；之後我更新程式，網站也會自動更新，不用再上傳壓縮檔。
步驟（只要做一次）：
1. Netlify → 進入 ada868 網站 →「Site configuration」→「Build & deploy」→「Continuous deployment」
   →「Link repository」（連結儲存庫）→ 選 GitHub，依畫面授權。
2. 儲存庫選：213919/my-first-project-everyday-is-good-day-website
3. 分支（Branch to deploy）選：claude/blissful-babbage-3y3w7m
4. Base directory 填：daily-news-app ；Build command 留空；其他欄位不用改（設定寫在 netlify.toml）。
5. 按部署。完成後用瀏覽器打開 https://ada868.netlify.app/api/news ，看到一大串文字（JSON）就代表成功。
   播放器下方狀態列會顯示「伺服器整理於 幾點幾分（每 10 分鐘更新）」。
沒有連結 GitHub 也能用，只是會自動改用較慢的瀏覽器抓取方式。

【二、iPhone 加到主畫面】
1. 用 Safari（不是 LINE 等 App 內建瀏覽器）開啟網址。
2. 點下方「分享」→「加入主畫面」。之後點桌面圖示就是全螢幕播放器。

【三、iPhone 桌面新聞小工具（Scriptable）】
1. App Store 下載免費的 Scriptable。
2. 打開播放器 → 右上齒輪 → 往下按「複製小工具程式碼」
   （失敗時按「查看程式碼」，全選後複製）。
3. 打開 Scriptable → 右上「＋」→ 貼上 → 上方改名為「聲讀」。
   （若之前裝過舊版，請把舊的內容全部刪掉，再貼上新版。）
4. 主畫面長按 →「編輯」→「加入小工具」→ Scriptable（中或大尺寸）。
5. 長按小工具 →「編輯小工具」→ Script 選「聲讀」。
點標題會在 Scriptable 裡全螢幕打開播放器並準備朗讀該則，再點一下播放鈕即可開始（iOS 規定發聲必須由使用者點擊）。
（iOS 不允許小工具直接打開「加到主畫面」的網頁 App；Scriptable 裡的播放器與主畫面 App 的收藏、設定不共用。）

【四、新聞來源】
- 主要內文：路透社、美聯社（兩家已停止提供公開 RSS，改用 Google 新聞搜尋取得，只有標題與連結）。
- 補充背景：BBC（中文繁體版）、NPR、半島電視台英文版。
- 原始資料：聯合國、世界衛生組織、國際貨幣基金、世界銀行、世界貿易組織、我國外交部、美國國務院。
- 事實查核：路透社事實查核、法新社事實查核。
- 在地中文：中央社（台灣財經）、科技新報（科技）。
- 法新社沒有找到公開的新聞 RSS，目前只收法新社事實查核。
- 每個來源是否抓得到，請看：播放器右上齒輪 →「新聞來源狀態」。
  主要網址失敗時會自動改用 Google 新聞搜尋作為備援。

【五、編輯原則（程式自動套用）】
1. 英文報導翻譯為繁體中文，卡片上保留「原文標題」與原文連結，方便查證。
   翻譯使用 Google 翻譯的免費介面（伺服器版由 Netlify 伺服器翻譯；瀏覽器版失敗時改走轉接服務）。
   這是非官方介面，不保證長期可用；翻譯失敗的英文新聞不會列出，狀態列會顯示幾則未列出。
2. 標題的情緒字眼改中性用詞：例如「痛批」→「批評」、「大勝」→「獲勝」、「震驚全球」→「引發全球關注」，
   卡片會標「標題用詞已調整」並顯示原標題；「羞辱、徹底失敗、應立刻制裁」這類評論性強的標題直接不收。
3. 評論、社論、分析、專欄文章不收。
4. 逐字稿依「發生了什麼 → 據某某報導 → 各方說法 → 下一步 → 消息來源」整理，只使用來源提供的內容，不另外加評論。
5. 每則都標明消息來源；程式會自動比對不同來源的同一事件，列出「另有某某的相關報導，可交叉查證」，
   卡片顯示「N 家來源」。只有單一來源時，逐字稿會明說「目前僅見單一來源」。
   路透社、美聯社只有標題時，若比對到高度相同的其他來源報導，會引用該來源的摘要並註明出處。
6. 涉及戰爭、制裁、領土、人權的新聞，朗讀前先提醒「部分內容來自當事方說法，未經獨立證實」，卡片也會標示。
- 以上分類、比對、用詞調整都是程式依關鍵字自動判斷，可能有誤，重要資訊請點「原文」確認。

【六、選擇新聞（橫向滑動圖卡）】
- 在播放器往下滑（或點右上角 ☰），會看到「全球政治／全球經濟／官方原始資料／事實查核／台灣財經／科技」各列圖卡，
  每一列都可以左右滑動。
- 點圖卡就開始朗讀那一則，並回到上方顯示逐字稿；點「全部播放 ▶」會依序播整列。
- 播放器標題下方有「來源」「相關」連結，可直接開啟各家原文。
- 圖卡右下的愛心可收藏，收藏的新聞會出現在最下方「我的收藏」。
- 往下瀏覽時，畫面底部會出現迷你播放列，可以暫停、下一則，點標題回到播放器。

【七、靜音模式與沒有聲音時】
- 已把網頁宣告為「媒體播放」，並在朗讀時搭配無聲音軌，
  目的是讓 iPhone 開著靜音鍵也能聽到朗讀（需 iOS 16.4 以上）。
  這個做法尚未在真實 iPhone 上測過，若靜音模式下仍然無聲，請先關閉靜音鍵使用，並回報 iOS 版本。
- 朗讀時，你正在播放的音樂可能會暫停（與一般 Podcast App 相同）。
- 調高音量（側邊音量鍵）。
- 設定 → 輔助使用 → 語音內容 → 聲音 → 中文，下載中文語音。
- 播放器右上齒輪 →「測試中文語音」，看下方診斷說明。
- 鎖定螢幕或切到其他 App 時，iOS 通常會停止網頁朗讀，請保持畫面開啟。

【八、檔案說明】
index.html            播放器主程式
rules.js              新聞來源清單、抓取整理與編輯規則（網頁與伺服器共用；要增減來源、調整用詞規則，改這個檔）
netlify/functions/news.mjs  伺服器版：整理新聞的程式（網址 /api/news，只有連結 GitHub 時才會執行）
netlify.toml          連結 GitHub 部署時的設定
manifest.webmanifest  加到主畫面設定
sw.js                 離線快取（只快取播放器本身，新聞仍需連網）
widget.js             Scriptable 桌面小工具程式碼
icons/                App 圖示
_headers              Netlify 標頭設定（讓小工具程式碼以正確中文顯示）

【注意】
- 只朗讀新聞來源提供的標題與摘要（及機器翻譯），非全文；重要資訊請點原文確認。
- 伺服器版直接向各來源抓取；瀏覽器版透過第三方轉接服務（rss2json、allorigins、codetabs）取得。
  哪個來源先回來就先顯示，中文來源最快出現；全部失敗時會顯示上次快取。
- 畫面開著時每 10 分鐘自動更新；從背景回到畫面時若超過 10 分鐘也會更新。
- 新聞來源與翻譯服務都沒辦法在開發環境先連線測試，請以「新聞來源狀態」的實際結果為準，有問題請回報。
